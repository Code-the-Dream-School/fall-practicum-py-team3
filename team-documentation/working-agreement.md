# Team Working Agreement

## Team Meetings/Communications
- Use Slack daily for async discussions.
- Team will meet weekly via Zoom every Thursday at 3:30 PM EST.
- Adhoc Zoom meetings with available team members as needed.

## Tasks and Responsibilities
- CJ will be creating basic tickets for each sprint.  
- We should choose a team leader to coordinate work (can rotate/select a different team leader)
- Team leader should delegate the tasks to each team member.

## How Blockers Will Be Raised:
- Blockers will be raised as soon as possible on Slack.  Team will need to figure out a solution quickly.

## Responding to Review Requests
- When team member have a PR to others to review; post it on Slack.
- Team member should be checking-in on Slack daily at a minimum.

## Pull Requests (before Merging)
- Every PR must have an associated JIRA ticket.
- The PR should be descriptive and clearly state purpose.
- Every PR must be approved by at least one team member.
- Large changes will need approval from CJ.
- The repo will run automated tests as part of every PR. These tests must pass before a PR can be merged into the main branch.

## Roles and Learning Opportunities
- Team leader roles can be switched around at least every sprint.
- Team members should address what they want to learn at every sprint.  This will help CJ and team leader to allocate the tasks accordingly.
