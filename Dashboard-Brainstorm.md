# UI

The dashboard starts with a title and the weather data for x cities in the center. The city names are derived from the API coordinates running in the pipeline. Each city will have their own boxes with their historical data including how many days fall under the AQI store if 1-5 and a "Not available" for the data with missing values. Later iterations will either allow for a selection box to open the information for individual cities or show all the cities at the same time.

This is a working rough draft subject to change.
